# Release Notes - Version 1.7.2 (Build 10)

**Release Date:** August 18, 2025  
**Build Type:** Production Release  
**File:** `app-release.aab` (67.5 MB)

## 🚀 **New Features**

### **App Update Notifications via FCM**
- **Push Notifications for App Updates**: Send notifications to all users when new versions are available
- **Direct App Store Links**: Users can tap notifications to go directly to Google Play Store
- **Auto-Generated Content**: Generate notification content based on app version and platform
- **Admin Dashboard Integration**: Web admin can send update notifications with preview functionality

### **Enhanced FCM Service**
- **Topic-Based Messaging**: Users automatically subscribe to `all_users` and `app_updates` topics
- **Smart URL Handling**: Automatically opens appropriate app store (Google Play/Apple App Store)
- **Notification History**: Track all sent update notifications in Firestore
- **URL Validation**: Validates app store URLs before sending notifications

### **Quiz Notifications via FCM**
- **Quiz Link Sharing**: Send quiz notifications with direct links to quiz instructions
- **Deep Linking**: Tap notification to navigate directly to specific quiz
- **Flexible Targeting**: Support for quiz ID or URL-based navigation

## 🔧 **Technical Improvements**

### **Error Handling**
- **Fixed UserManagement Component**: Resolved undefined property errors in admin user management
- **Null Safety**: Added proper null checks for user roles, names, and email fields
- **Data Validation**: Enhanced data fetching with default values for incomplete records

### **Code Quality**
- **Production Ready**: Disabled debug logging and enabled production optimizations
- **Tree Shaking**: Optimized font assets (99%+ reduction in icon font sizes)
- **Performance**: Improved app startup and notification handling performance

## 📱 **User Experience**

### **Notification Flow**
1. **Admin sends update notification** via web dashboard
2. **Users receive push notification** with app update details
3. **Tap notification** → **Opens app store** → **Update app**

### **Quiz Notifications**
1. **Admin sends quiz notification** with quiz link
2. **Users receive notification** about new quiz
3. **Tap notification** → **Opens quiz instructions** → **Start quiz**

## 🛠 **For Developers**

### **FCM Integration**
```json
// App Update Notification Data
{
  "actionType": "app_update",
  "actionUrl": "https://play.google.com/store/apps/details?id=com.mcqquiz1.app"
}

// Quiz Notification Data
{
  "actionType": "quiz",
  "quizId": "your_quiz_id",
  "actionUrl": "/quiz/your_quiz_id/instructions"
}
```
