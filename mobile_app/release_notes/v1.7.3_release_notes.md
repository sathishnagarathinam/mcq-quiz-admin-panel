# Release Notes - Version 1.7.3 (Build 11)

## 🚀 **Major Feature: One-Time Login Implementation**

### **What's New**
- **Seamless Login Experience**: Users now only need to enter their password once! After the first successful login with "Remember Me" enabled, the app will automatically log users in on subsequent launches.
- **Enhanced User Experience**: No more repetitive password entry - just open the app and you're in!

### **Key Features**

#### 🔐 **One-Time Login**
- **Automatic Authentication**: App automatically logs in users using securely stored credentials
- **Smart Fallback**: If auto-login fails, users can still login manually
- **Secure Storage**: Passwords are encrypted before storage with 30-day expiry for security

#### 🎯 **Improved User Interface**
- **App Name Update**: Changed from "Dak-shin Postal Academy" to "Dakshin Postal Academy" across all screens
- **Default Remember Me**: "Remember Me" option is now enabled by default for better user experience
- **Enhanced Splash Screen**: Intelligent auto-login detection during app startup

#### 🛡️ **Security Enhancements**
- **Encrypted Credentials**: Passwords are encrypted using secure algorithms before storage
- **Automatic Expiry**: Stored credentials automatically expire after 30 days
- **Device Validation**: Maintains existing device security and one-user-per-device policy
- **Error Handling**: Failed auto-login attempts automatically clear stored credentials

## 🔧 **Technical Improvements**

### **Authentication System**
- Enhanced credential storage service with encryption/decryption capabilities

## 🔒 **Security & Privacy**

### **Data Protection**
- **Encrypted Storage**: All stored credentials are encrypted
- **Automatic Cleanup**: Expired credentials are automatically removed
- **Secure Fallback**: Failed authentication clears stored data

### **Privacy Compliance**
- No sensitive data stored in plain text

## 📋 **Installation & Upgrade**

### **For New Users**
1. Download and install the app
2. Complete onboarding and disclaimer
3. Login with email and password
4. "Remember Me" is enabled by default

### **For Existing Users**
