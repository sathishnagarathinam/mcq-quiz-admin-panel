# Privacy Policy Compliance - Dakshin Postal Academy

## 📋 **Data Collection Declaration**

### **Personal Information Collected**
1. **Phone Number**: For user authentication and account creation
2. **Email Address**: For account recovery and notifications
3. **Name**: For personalized user experience
4. **Quiz Performance Data**: Scores, progress, and analytics
5. **Device Information**: For app optimization and security

### **How Data is Used**
- **Authentication**: Secure login and account management
- **Personalization**: Customized quiz experience and progress tracking
- **Analytics**: App performance improvement and user experience enhancement
- **Security**: Fraud prevention and account protection
- **Communication**: Important updates and notifications

### **Data Sharing**
- **No Third-Party Sharing**: User data is not sold or shared with third parties
- **Service Providers**: Limited sharing with Firebase (Google) for authentication and analytics
- **Legal Requirements**: Data may be disclosed if required by law

### **Data Security**
- **Encryption**: All sensitive data is encrypted in transit and at rest
- **Secure Storage**: User credentials stored using Flutter Secure Storage
- **Access Control**: Strict access controls and authentication required

## 🔒 **Permissions Justification**

### **Required Permissions**
1. **INTERNET**: Essential for app functionality, authentication, and content delivery
2. **ACCESS_NETWORK_STATE**: To check connectivity and provide offline features
3. **POST_NOTIFICATIONS**: For quiz reminders and important updates
4. **CAMERA**: For profile picture upload (optional)
5. **READ_MEDIA_IMAGES**: For profile picture selection (Android 13+)

### **Removed Permissions** (Policy Compliance)
- ❌ **RECEIVE_SMS**: Removed - Using Firebase Auth instead
- ❌ **READ_SMS**: Removed - Using Firebase Auth instead  
- ❌ **WRITE_EXTERNAL_STORAGE**: Removed - Using scoped storage

### **Optional Permissions**
- **CAMERA**: Only requested when user wants to upload profile picture
- **READ_MEDIA_IMAGES**: Only requested for profile picture selection
